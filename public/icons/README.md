# PWA icons

Drop two PNGs here named `icon-192.png` (192×192) and `icon-512.png` (512×512).

Easiest path: head to https://realfavicongenerator.net or https://favicon.io, upload an AdaptiveFit logo, download the bundle, copy these two files. The PWA manifest already points at them.

If you don't have a logo yet, a placeholder will install fine — Pixel 9 just shows a default home-screen icon.
